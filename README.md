# 🧠 思维超能力 — 陪孩子从小学到大学的思维成长工具

在《思维超能力手册》五册（50 个超能力）的基础上，扩展成一个**长期使用**的思维与认知训练工具：
**12 颗思维星球 × 6 个成长阶段 · 131 个思维超能力 · 9 种脑力游戏 · 60 个思辨话题 · 成长档案**。

纯网页应用（PWA）：手机、平板、电脑打开就能用，可以"添加到主屏幕"像 App 一样使用，不需要服务器，可以离线使用，没有广告，所有数据只存在本机浏览器里。

---

## 设计思路（从思维教育专家的角度）

| 原则 | 在工具里怎么体现 |
| --- | --- |
| **用一辈子的工具，要随孩子一起长大** | 6 个成长阶段：🌱萌芽（一二年级）→ 🌿抽枝（三四年级）→ 🌳成林（五六年级）→ 🚀启航（初中）→ 🔭远望（高中）→ 🌌星辰（大学及以后）。内容、游戏题库、思辨话题都按阶段分级，孩子可以提前学习下一阶段的内容 |
| **思维不只是"聪明"，是一整套能力** | 12 颗星球：心智基石、超级学习力、问题解决、逻辑与批判、科学与概率、决策与经济、系统思维、创造力、情绪与社交、自我管理、计算与AI、哲思与智慧 |
| **知道 ≠ 会用（迁移）** | 每张卡都有"试一试"真实生活任务，写下实践记录才算真正掌握（奖励比"读完"更高） |
| **先挑战再解锁** | 读完故事要通过闯关题才能解锁，主动思考而不是被动阅读 |
| **不会忘（遗忘曲线 + 主动回忆）** | 学过的卡按 1→2→4→7→15→30→60→120 天自动安排复习，复习时先回忆再答题 |
| **游戏要训练能迁移的策略** | 不做单纯的"记忆/反应速度"训练（研究显示很难迁移），而是：找规律、识别谬误、识别认知偏差、费米估算、期望值决策、自信校准、逻辑推理、水平思考、发散创意 |
| **思维在对话中成长** | "思辨时刻"参考儿童哲学（P4C）：没有标准答案的问题，全家一起讨论，练习说理由、听理由、改变想法 |
| **有趣才能坚持** | 每日任务（约 15 分钟）+ 宝箱、星星、XP 称号（思维小种子 → 思维宗师）、连续打卡🔥、22 枚徽章、收藏 |
| **看得见的成长** | 成长档案：12 星球思维雷达图、12 周学习热力图、徽章墙、实践/思辨/日记时间线 |

**新增 81 张卡**，重点补全中学和大学阶段，例如：

- 🌱 小学：问题宝宝、给情绪起名字、给机器人下指令（算法）、倒着推、组合创新、思维导图、两分钟法则、拆解大象、论证三件套、锚定效应、10/10/10、瓶颈思维、SCAMPER、六顶思考帽、交错练习、习惯回路、要事第一、控制二分法、智识谦逊、二分查找、勇敢说不、费米估算
- 🚀 初中：快思考与慢思考、达克效应、MECE、极端情况检验、逻辑谬误、充分与必要、钢人论证、横向阅读（SIFT）、图表会说谎、样本量、安慰剂与双盲、期望值、损失厌恶、单向门/双向门、事前验尸、囚徒困境、反馈回路、公地悲剧、眼镜蛇效应、发散与收敛、孵化效应、接住反馈、心理韧性 ABCDE、WOOP、注意力保卫战、AI 是怎么学的、调试思维、苏格拉底提问、思想实验
- 🔭 高中：多元思维模型、认知负荷、贝叶斯思维、基础比率、均值回归、可证伪性、边际思维、比较优势、结果≠决策质量、杠杆点、涌现、身份型习惯、递归、与 AI 共学、地图不是疆域、无知之幕、伦理思考框架、举证责任、自我关怀
- 🌌 大学：人生设计（奥德赛计划）、林迪效应、意义感、选择悖论、主题阅读、反脆弱、能力圈、范式转移

## 怎么用

### 方式一：GitHub Pages（推荐，免费）
1. 把代码合并到 `main` 分支。
2. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
3. 推送后 Actions 会自动测试并部署，地址类似 `https://<用户名>.github.io/thinkingpowers/`。
4. 用手机/平板打开，浏览器菜单选"添加到主屏幕"。

### 方式二：本地运行
```bash
python3 -m http.server 8000
```
然后打开 http://localhost:8000

## 给家长的建议

1. **每天 15 分钟**，固定时间（如晚饭后）完成每日任务，比周末突击有效。
2. **陪孩子完成"试一试"**——这是整个工具最重要的部分。
3. **思辨时刻多问"为什么""你怎么知道的"**，少给结论；家长也可以说"我改变主意了"。
4. **表扬过程而不是聪明**。
5. **定期导出备份**（家长中心 → 数据备份），换设备时导入即可。

家长中心用乘法题验证，可以调整成长阶段、查看学习概况、阅读使用指南。

## 开发

- 无构建步骤：原生 ES Modules + CSS。
- `js/data/cards/*.js`：思维卡内容（加新卡只需往数组里加对象，测试会检查格式）
- `js/data/games.js`：游戏题库；`js/data/talks.js`：思辨话题；`js/data/badges.js`：徽章
- `js/logic.js`：纯逻辑（间隔重复、推荐、评分、数列/期望值生成），有单元测试
- 修改文件后运行 `npm run build:sw` 更新离线缓存列表
- 测试：`npm test`
